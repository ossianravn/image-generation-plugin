# Vendored Agent Plugins schemas

These unmodified JSON schemas were retrieved on 3 October 2026 from the published Agent Plugins 1.0.0 schema URLs:

- [plugin.schema.json](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json)
- [mcp.schema.json](https://agent-plugins.org/schemas/1.0.0/mcp.schema.json)

`npm run validate` uses these versioned copies for deterministic local and CI validation. The specification also contains semantic requirements that a JSON Schema cannot establish, such as executable resolution and host behavior.
