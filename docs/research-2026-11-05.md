# Provider update research: GPT Image 2.6 and Nano Banana 2.1

**Checked:** 5 November 2026.
**Purpose:** evidence for the 0.3.0 catalogue and option changes. The [earlier baseline](research-2026-10-03.md) still holds for packaging, hosts, MCP, Replicate, and OpenRouter.

## OpenAI GPT Image 2.6

| Finding | Plugin consequence |
| --- | --- |
| `gpt-image-2.6-flare` (fast iteration) and `gpt-image-2.6-sunburst` (detailed work) support only `/v1/images/generations` and `/v1/images/edits`. Token prices match GPT Image 2.5. | Added both to the catalogue on the existing Images route. 2.5 stays: the guide still uses it in most examples. |
| Both 2.6 models support a `complexity` field (`low`, `medium`, `high`; default `high`), markup-guided edits, SVG output, and animated GIF output. | New `complexity`, `frame_count`, and `frame_duration_ms` controls, `gif`/`svg` formats, and a `markup` input. |
| GPT Image 2.5 adds `xhigh` and `max` quality. Custom sizes: multiples of 16, ratio 1:3 to 3:1, edges up to 3840, 655,360 to 8,294,400 pixels. Transparency needs PNG or WebP. | Quality values added. Sizes and transparency are now checked before a paid request. |
| GIF: generations only, `frame_count` 2–16 (default 9), `frame_duration_ms` 20–2000 (default 200), frame size `auto` or multiples of 16, within an unpublished request pixel budget. No streaming or `output_compression`. | GIF requests with references, masks, or markup are refused locally. Saved GIFs record frame count and total duration. |
| SVG: generations only, `n` must be 1, base64 UTF-8 XML documented as static (no scripts, external resources, or embedded rasters). The edit endpoint does not accept SVG input. | SVG outputs are saved as `image/svg+xml` after a static-content check and rendered for previews. SVG remains rejected as an input image. |
| The API reference, not the guide, documents an `svg` object `{ model, reasoning: { effort } }` naming the text model that writes the SVG. Accounts with SVG author selection enabled must send `svg.model`; others must omit it. The response adds `svg_usage` for the author's tokens. A live run without it failed with `missing_required_parameter` for `svg.model`. | New optional `svg_model` control, sent as `svg.model`. A missing-author error maps to `SVG_MODEL_REQUIRED`. `svg_usage` is kept in job usage. Author reasoning effort is not exposed. |
| Markup: a separate transparent PNG with the first image's width and height after orientation; each at most 16,777,216 pixels; annotation file at most 50 MB; never combined with `mask`. Supported on 2.5 and 2.6. | `markup` is validated in preparation and sent as a multipart file. |
| Blocked requests return `error.type: image_generation_user_error`, `error.code: moderation_blocked`, and optional `moderation_details` (stage and coarse categories). | Errors now keep these identifier fields, never provider message text, and map to `MODERATION_BLOCKED` or `IMAGE_USER_ERROR`. |
| The Images API `user` field is deprecated in favour of `safety_identifier`. | No change: the plugin sends neither. |

## Gemini Nano Banana 2.1

| Finding | Plugin consequence |
| --- | --- |
| `gemini-nano-banana-2.1` updates Nano Banana 2 (`gemini-3.1-flash-image`); Google recommends it for new projects. | Added; Nano Banana 2 stays because it is the only route with 512px output. |
| Output sizes `1K` (default), `2K`, `4K`; no 512px. Adds 1:4, 4:1, 1:8, and 8:1 aspect ratios. | Resolution values are listed in the descriptor; aspect ratios pass through unchanged. |
| Thinking levels `minimal`, `medium` (default), `high`, sent as `generation_config.thinking_level`. Thinking cannot be disabled. | New `thinking_level` control for this model only. |
| Up to 14 references (10 objects and 4 characters). | Reference limit 14. |
| Web and image search grounding through the `google_search` tool. Responses then carry a `search_suggestions` HTML snippet meant for rendering in the app's UI. | Not exposed: agent hosts have no place to render search suggestions. |
| The pricing page lists $30 per million image output tokens (about $0.034 per 1K image), half Nano Banana 2's rate. | Informational. |

The plugin calls the stable `v1` Interactions endpoint. Google's new examples use `v1beta` with an `Api-Revision` header, but the 5 November live run confirmed Nano Banana 2.1 on `v1`.

## Gaps in the sources

- The announcement shows a sketch becoming an animated character. The API guide limits GIF output to generations without input images, so reference-driven GIFs may be ChatGPT-only. The plugin refuses them until a live test shows otherwise.
- The GIF request pixel budget and whether `n` above 1 works for GIFs are not published.
- No reference or output-count limit is published for 2.6. The plugin leaves the reference limit to the API and keeps 2.5's output limit of 10.
- GIF and SVG pricing is not published. SVG also bills the tokens of a separate authoring model.
- `prompt_rewriter` is named in the guide but never defined.
- Which text models may author SVGs is not documented. `gpt-6-astra`, the guide's own mainline example, worked on 5 November.
